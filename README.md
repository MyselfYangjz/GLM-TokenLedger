# 用量账本



> **用途声明：** 本项目仅供教育、学习和实验用量核算使用。请遵守智谱的服务条款及账号使用规则，不得将本工具用于规避授权限制、共享个人账号或其他违规用途。

双击 **index.html** 即可离线使用，无需启动脚本、服务或目录授权。

1. 点击“选择映射文件”，选择 `用户映射.json`（也支持其他文件名的相同格式 JSON），并允许浏览器读写该文件。
2. 点击“导入账单”，选择智谱 AI 费用明细 `.xlsx`，支持多份文件或拖拽导入。
3. 勾选参与统计的账单；点击用户名单元格填写对应用户，也可以打开“用户名映射”提前配置。
4. 按消费日期选择区间，或点击“全部时间”；切换 K / M，或导出当前表格为 CSV。
5. 使用 Chrome / Edge 选择文件并授权后，新增、修改、删除映射会自动写回同一 JSON；下次打开时重新选择该文件。

## 统计口径

- 仅统计产品类型为“模型推理”的记录。
- 汇总“用量”列，包含输入、输出、缓存命中；单位必须为 token。
- 每把 API key 一行，同一用户的多把 key 分别展示。
- 1 K = 1,000 token；1 M = 1,000,000 token。分别展示 3 位、6 位小数，保留到单个 token；表格、汇总和 CSV 使用相同口径。样例总量为 3,394,473.448 K / 3,394.473448 M。
- 不重复累加“抵扣用量”，也不使用费用金额推算消耗。
- 同一账单号且统计内容相同的明细只计一次；账单号相同但统计内容不同，会提示冲突并暂停统计。取消勾选或删除错误账单后继续。
- 搜索会同时筛选表格、汇总卡片和导出结果。
- 样例账单支持按自然日筛选；跨自然日的单条明细会提示不能准确拆分，不会任意分配用量。

## 本机保存

每次打开或刷新页面，用户名映射均为空，需重新选择 JSON 文件。选择文件会整体替换本次页面的映射；取消选择不改变当前数据，无效 JSON 会提示错误并保留当前有效映射。

映射文件句柄只用于本次页面，不写入浏览器缓存。在 Chrome / Edge 中通过“选择映射文件”获得读写授权后，页面修改会依次写回所选文件，并显示“正在同步”或“已同步”。保存失败会显示“映射未同步”，保留页面修改，可点击“重试保存”或导出备份；切换文件只影响新文件。

不支持文件读写选择器的浏览器使用只读导入，并明确提示需导出保存。JSON 格式如下：

```json
{
  "version": 1,
  "mappings": {
    "your-api-key": "张三"
  }
}
```

启动时会清除 IndexedDB 中遗留的旧映射、迁移标记和目录记录。账单、日期和展示单位继续保存在当前浏览器；删除账单保留本次映射及原始 Excel 文件。

页面及 Excel 解析库均内嵌在单个 HTML 内，不请求外部服务，导入账单和映射文件在本机浏览器处理。项目根目录的 `用户映射.json` 已加入 `.gitignore`。

## 开发与验证

```sh
python3 scripts/build.py
npm test
npm install
npx playwright install chromium --no-shell
npm run test:browser
```

`src/` 为源码，`scripts/build.py` 将样式、脚本及 Excel 解析器合成为 `index.html`。Python 仅用于开发构建，普通使用只需要 `index.html`。

21 项单元测试核对实际样例账单、日期边界、重复和冲突记录、K/M 单位换算、异常数据、精度、映射文件格式、写入顺序、权限、写入失败和重试。

10 组浏览器测试断网运行：7 组直接打开本地 HTML 验证只读回退、账单导入、K/M 和 CSV、账单恢复和删除、移动端布局、旧缓存清理及映射刷新清空；3 组在模拟本机页面中使用浏览器原生文件句柄验证映射新增、表格编辑、删除、文件切换、取消选择、写入失败及重试。系统文件选择窗口由测试代替。

Excel 解析使用 SheetJS CE 0.20.3，许可证见 `vendor/SHEETJS-LICENSE.txt`。
