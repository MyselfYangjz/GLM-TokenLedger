# API 用量统计工具需求

## 已确认

- 本地 HTML，双击打开，支持离线使用；账单在本机浏览器处理。
- 支持导入多份智谱 AI 费用明细 XLSX，并勾选参与统计的账单。
- 支持配置 API key 与用户名的映射，一个用户名可以对应多把 key。
- 统计表每把 API key 一行，列为 API key、用户名、用量。
- 产品类型仅纳入“模型推理”。
- 用量展示可在 K 与 M 之间切换，1 K = 1,000 token，1 M = 1,000,000 token；汇总、表格和 CSV 统一换算。
- 可按消费日期选择统计区间，包含起止当天；不选日期时统计全部。
- 直接双击 `index.html`，手动选择 `用户映射.json`，再导入账单；无需启动脚本、服务或选择项目目录。
- 每次打开页面映射为空，删除浏览器中旧映射、迁移标记及目录句柄；不恢复、合并或缓存用户名映射。账单和筛选条件继续保存在当前浏览器。
- 选择新的映射文件会整体替换本次映射；取消选择或无效文件不改变当前有效映射。
- 选择映射 JSON 并授予读写权限后，新增、编辑和删除映射自动写回同一个文件；写入失败明确提示，保留页面修改并支持重试。文件句柄不缓存，每次打开重新选择。只读浏览器保留导入及导出回退。

## 已确认的处理规则

- 用量口径：累加“用量”列，包含输入、输出和缓存命中。
- 未映射 API key：保留在统计结果中，用户名显示“未配置”，支持直接填写。
- 多份账单重叠：同一明细仅统计一次，显示重复记录数量；同一账单号内容冲突时提示处理。

## 用量占比

- 统计表最后增加一列，展示每把 API key 的用量占比；仅在 HTML 页面显示，CSV 不增加占比列。
- 占比 = 当前统计结果中该 API key 的用量 ÷ 当前总用量；搜索、已选账单和日期范围变化都会同步影响分母。
- 页面显示保留两位小数；总用量为 0 时各行显示 0.00%。占比使用带符号用量计算，以保持与实际消耗汇总一致。
